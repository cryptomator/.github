# Contributing to Cryptomator

## 🐞 Did you find a bug?

- Ensure you're running the latest version.
- Ensure the bug was not already reported by searching the project's existing issues. You can also check out our [FAQ](https://community.cryptomator.org/c/kb/faq).
- If you're unable to find an open issue addressing the problem, submit a new one.

## 🛠️ Did you write a patch that fixes a bug?

- Open a new pull request with the patch.
- Ensure the PR description clearly describes the problem and solution. Include the relevant issue number if applicable.

## ✨ Do you intend to add a new feature or change an existing one?

- Suggest your change by submitting a new issue and start writing code.

## 🤖 Use of Generative AI

You may use generative AI tools to help you write code, tests, or documentation. However, you remain the author of your contribution and **you are responsible for every line of it**. Our reviewers' time is limited, so if you use AI, we expect the following:

1. **Understand your change.** You must be able to explain what your contribution does and why. Do not submit output you do not understand yourself.
2. **Verify your change.** Review and test the result before submitting it. AI tools confidently produce code that looks right but isn't.
3. **Engage in the review.** Answer reviewers' questions and address their feedback yourself, even if your AI tool can't. If AI helps you draft a reply, make sure it is accurate and actually addresses the point raised.
4. **Disclose AI usage.** Tick the corresponding checkbox in the pull request template if AI tools generated substantial parts of your contribution. Simple autocompletion does not need to be disclosed.
5. **Respect the license.** Your contribution will be released under the project's license. Make sure the generated content doesn't introduce third-party code or licensing restrictions.

> [!IMPORTANT]
> Contributions that do not meet these expectations, such as unverified or low-quality AI output, will be closed without further review.

## 🤝 Code of Conduct

Help us keep Cryptomator open and inclusive. Please read and follow our [Code of Conduct](https://github.com/cryptomator/.github/blob/main/CODE_OF_CONDUCT.md).
